Asistente asistencia

Falta configurar la clave de la API de Claude (ANTHROPIC_API_KEY) en Render. Sin ella no se pueden leer las fotos.
1

Carga el checador

Sube el Excel que genera el CHECADOR INTERNO. Con él se arma la lista del personal y se revisan las horas.

2

Sube las incidencias

Sube el Excel de INCIDENCIAS tal como lo mandan (puede traer varias semanas, una hoja por semana). Cada semana se guarda por separado.

2

Imprime la lista

Elige cualquier día de la semana; la lista sale de lunes a sábado con las fechas correctas y el personal del último checador.

3

Revisa la semana

Toma una foto por hoja, de frente y con las cuatro esquinas negras visibles. Antes, carga el checador de esa misma semana.

Turnos y límites

El horario sirve para calcular la jornada de cada día y los retardos; el límite es cuántas horas a la semana se trabajan antes de contar tiempo extra. Si dejas un campo vacío se usa el horario del checador.
